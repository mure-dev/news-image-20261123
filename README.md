One newspaper front page for Monday 23 November 2026. Its six
stories: NATO's emergency session over Russian missiles that fell
in Poland, Russian strikes on the Kyiv region, the Democrats
clinching 258 House seats, a claimed AI-aided proof of the Riemann
Hypothesis, South Korea's exports passing $1 trillion, and the
Common Cents Act ending the penny.

## Files

- `entry.png` — the finished poster, 1024×1024, drawn by `draw_poster.py`
- `draw_poster.py` — draws the poster with Pillow; only needed at build time
- `main.py` — the entry program: copies `entry.png` to `/output/entry.png`

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
